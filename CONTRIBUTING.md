# Contributing

Contributions are welcome! Please ensure your pull request adheres to the following guidelines:

## Guidelines

- **Technical resources only**: Submit specs, SDKs, drivers, harnesses, wrappers, protocol tooling, and similar technical implementations.
- **No marketing content**: Do not submit partner logos, business blurbs, or marketing pages.
- **One item per PR**: Keep pull requests focused on a single addition or change.
- **Include context**: Provide the URL and a one-line explanation of why the resource is relevant to MHS.
- **Be honest about status**: Clearly indicate if a resource is:
  - Preview or apply-only
  - Unofficial or community-driven
  - Work-in-progress or name-holder
  - Not affiliated with Anthropic
- **Verify links**: Ensure all URLs are accessible and point to active resources.
- **Follow the format**: Match the existing style and structure of the list.

## Suggesting changes

1. Fork this repository
2. Create a new branch
3. Make your changes
4. Submit a pull request with a clear description

Thank you for contributing!
